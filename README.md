# TrailOverflow

TrekIt is a web-based Trekking Management Application that connects Admins, Trek Staff, and Trekkers on one platform. Admins create and manage trek routes, assign staff, and monitor bookings; Staff handle slot availability and trek status updates; Trekkers can browse, search, and book treks, track their booking history, and get automated reminders before their trip — all backed by a Flask + VueJS stack with Redis/Celery for background jobs like reminders, monthly reports, and CSV export of trek history.
